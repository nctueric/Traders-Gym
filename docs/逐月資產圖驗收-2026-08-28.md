# 逐月總資產圖｜2026-08-28

## 位置與互動

持倉總覽的財務摘要下方新增原生 Canvas 逐月增減堆疊圖。最近12個月／24個月／全部月份；可點柱子、鍵盤操作月份按鈕或選單查看明細。另提供全部月份表格及當月入出金原始日期、金額、幣別、備註與ID。保留減半後柱寬，柱間空隙再縮減80%，月份與數字置中對齊；底部月份使用 Jan–Dec，僅 Jan 下方加註年份。窄畫面保留字級並橫向捲動。

## 對帳口徑

- 深色：已閉環交易的累計已實現損益，與現有總覽口徑一致。
- 淺色：當月底剩餘 FIFO 持倉的未實現損益。深淺合計為總損益，不再疊加一份總損益。
- 黃色：當月 DEPOSIT；紅色：當月 WITHDRAWAL（包括既有帳本的現金校正）。OPENING_BALANCE 不當作新入金，FEE／TAX 不當作提款。
- 灰色本金／其他帳務淨額＝月末總資產－總損益－本月淨入金。包括以前月份資金、期初校正、未閉環部分出場與其他費用，不宣稱等同純投入本金或交易獲利。
- 每月色帶依正負方向增減堆疊，總資產以數字顯示於加減後的位置，四捨五入至整數美元，移除原黑色短線與其圖例。明細、資料表及帳本仍保留原始精度；虧損深／淺紅色，負項向下扣減。
- 本月總資產沿用現有估值引擎与報價，歷史月份僅使用當月及以前的成交、資金與行情，不使用未來行情或目前報價回填過去。
- 帳本 UTC 月份分組。所有月份按本次 USDTWD 換算美元等值，不代表逐月歷史匯兌報酬。
- 缺期初資金或未確認資金幣別時保留月份缺口；不以零資產編造歷史成長。缺歷史收盤價的成交價估值、距月底超過7日的行情皆有提示。

## 使用者驗收

1. 持倉總覽查看逐月圖，核對本月整數資產標籤與上方總資產（僅顯示四捨五入差異）；確認柱寬不變、間隙只剩原本20%、月份英文縮寫、僅一月帶年份。
2. 選取有入金／提款的月份，展開原始紀錄核對。
3. 核對總損益＝已實現＋未實現，全部色帶含扣減後＝總資產。
4. 點選月份、使用選單及鍵盤選取，確認同一月份的數據與證據同步。
5. 歷史缺資料應明確顯示，不能將匯入校正或新投入資金誤認為交易獲利。
