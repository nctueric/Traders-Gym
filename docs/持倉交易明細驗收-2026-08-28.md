## 本次功能

- 「目前持倉」標的欄新增「交易紀錄・N筆」，可獨立展開／收合。
- 只顯示當前 cycle 的完整 fills，不混入之前閉環或其他帳戶。
- 顯示日期（台北）、買賣與建倉／加碼／減碼／回補、數量、成交價、成交金額、費用、成交前後股數、備註、反手拆分來源。
- 金額使用成交原幣；成交金額不含費用。剩餘成本沿用 FIFO，不重算為所有買單的平均成本。
- 預設新成交在上，相同時間依來源順序；不從日線推測盤中路徑。
- 展開狀態以 cycle ID 保留，報價刷新與排名更動不收合；切換帳號重置。
- 「定位成交」開啟既有持倉 K 線視窗，選取該 fill 事件與當日 K 線；缺少當日日K時顯示限制，不代選下一交易日。
- 父表固定欄規則限定直接子表格，避免內層交易明細被固定欄樣式污染。

## 使用者驗收

1. 開啟本機版 →「目前持倉」→ 點股票下方「交易紀錄」。
2. 核對每筆買賣、成交後股數與目前持倉，確認部分減碼仍在清單。
3. 點「定位成交」，確認選中正確成交及日期，按 Esc 返回原入口。
4. 等待背景行情刷新，確認明細仍展開、原始成交數值不變。
5. 在寬螢幕及窄螢幕確認區域捲動、固定標的欄與明細可讀。
