# TraderGym 板塊輪動｜本機交付

日期：2026-10-21。基準 `a2425d3`，功能分支 `feat/sector-rotation`。本次未發布正式環境，未修改真實帳本。

## 開啟

沿用專案 Node.js 22.13+ 環境，使用隔離的本機資料目錄啟動：

```sh
LOCAL_CLOUD_DIRECTORY=./.wrangler/rotation-acceptance LOCAL_MAIL_PREVIEW=true APPLICATIONS_OPEN=true npm run dev -- --port 3107
```

開啟 `http://127.0.0.1:3107/demo`，點頂部「板塊輪動」。訪客使用真實行情；研究設定只存在記憶體。會員設定走既有驗證與 D1 偏好服務，本機環境使用隔離 D1/R2。

預設 SPY、週線、12 期尾跡、11 大板塊。可選 QQQ／SHV、日線、6／24 期，以及12個主題 ETF。點圖或排名列選取標的，可隔離、查看中文規則與證據、最近象限變化、日週對照及基準100價格比較。手機圖表可在框內左右滑動，表格也獨立捲動。鍵盤可選取圖上標的與操作時間軸；時間軸朗讀實際日期。

## 計算與資料契約

`tg-rotation-v1`：RS=調整後價格/基準調整後價格；X=100×WMA(RS,10)/WMA(RS,30)；Y=100×X/X三期前。WMA 由舊至新權重1…N，33期暖機。這是自有算法，不是原版 JdK RRG。

- `GET /api/market/rotation?symbols=XLK,SMH&benchmark=SPY&interval=weekly&mode=history`
- `symbols`：23標的白名單，預設11板塊；`benchmark`：SPY/QQQ/SHV；`interval`：daily/weekly；`mode`：history/latest。
- 回傳兩個週期的完整座標序列，方便切換與日週對照；最新模式以快取歷史加近期資料重算，不新增每分鐘軌跡點。
- 回傳 `version/calendarVersion/source/quoteTime/fetchedAt/completedThrough/marketOpen/rows/errors/warnings`。列含每日／每週座標、完成狀態、方向、速度、動能差、近月與相對報酬。
- 讀取三年、展示兩年；日曆明確支援2023–2028（版本 `nyse-2023-2028-v1`），涵蓋正常休市、提早收盤、DST及2025-01-09特別休市。之後年份需先更新日曆。
- 共同交易日曆補出缺口；缺值重設暖機、不補零、不跨缺口連線。週資料只在該週最後交易日完成；日線回放不讀取後來的週收盤。
- 相同資料截到任一截止日，應與完整資料的同日結果一致。供應商歷史修訂可能改變回放；不是當時行情封存或交易回測保證。
- 歷史快取以交易日、最近完成日與30分鐘區段失效。最新資料60秒快取；並行請求合併並共用現有上游3路限制，最後一個使用者取消才中止共用請求。
- 近期與歷史價格的調整比例必須一致；若不一致重新載入歷史。盤中使用同一日同一來源的調整因子，行情時間差不得超過2分鐘、行情年齡不得超過20分鐘；不滿足時停用預覽。可能延遲會持續顯示，不宣稱交易所零延遲。
- 基準失敗回傳502；前端保留舊畫面並提示過期。單一標的失敗回傳逐標的錯誤，保留該標的歷史、退出最新排名；成功恢復解除過期。
- 只有最新模式、可見頁面、正常交易時段自動輪詢；收盤轉換時額外核對一次。回放、背景頁及離開研究頁停止新增行情請求。歷史播放不使用暫時端點。

## 保存與相容性

`member_preferences` JSON增加 `rotation`，欄位為 `benchmark/interval/themes/tail/preview`。沿用既有驗證、使用者隔離與原子偏好更新；不改帳本 schema，不需資料遷移。失敗時保留畫面選擇並提供重試，不宣稱已保存。研究頁在帳本尚未建立或未載入時仍可使用。

頁面按需載入，沿用工作台導覽；未加入圖表套件。為通過既有型別檢查，持倉路徑計算的日期字串呼叫改為明確 Date，計算方法不變。

## 驗證

最終自動化結果：547項測試全部通過，TypeScript、ESLint及正式建置通過。

- 自動化覆蓋：公式/暖機/四象限/方向速度；截斷資料一致；缺日與短週；休市/DST；調整因子缺失與修訂；時間不同步；基準與單標的錯誤；限流/超時；恢復；偏好會員隔離；回放/背景/離頁輪詢停止；象限事件不跨缺口。
- 隔離瀏覽器測試：23標的、24期；選取與隔離、歷史播放、錯誤重試、偏好失敗重試、日週切換、手機、卸載。1440px桌面與390px手機截圖位於 `.impeccable/review/rotation/`，使用明確標示的合成行情。
- 實際瀏覽器：本機 `/demo` →「板塊輪動」→11個真實板塊行情，無瀏覽器例外。實際API：SPY基準＋XLK/SMH，200，無逐標的錯誤。沒有宣稱已驗證真實盤中整個交易日。
- 載入後瀏覽器選取測量約21–32ms；390px裝置文件寬390px，圖表標籤12–14px、點選範圍44px。這是本機量測，不是上游行情延遲SLA。
- 介面審閱兩項發現（手機圖表過小、時間軸缺日期朗讀）已獲確認解決；審閱結論限於列出的修正。

檢查指令：`npm test`、`npm run lint`、`npx tsc --noEmit`、`npm run build`。

可重跑隔離瀏覽器驗證：先執行 `node tests/serve-rotation-fixture.mjs`，另執行 `node tests/verify-rotation-browser.mjs`。測試需 Playwright；若不在專案安裝，可用 `ROTATION_PLAYWRIGHT_MODULE` 指定其入口，並用 `ROTATION_BROWSER` 指定 Chrome執行檔。驗收服務只聽127.0.0.1:3108，沒有帳本或外部行情寫入。
