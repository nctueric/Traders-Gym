# 新增交易：集中式登錄

## Direction contract

- THESIS：已成交後以同一頁完成成交、策略與整筆持倉計畫；左側共享複盤圖，右側輸入，下方確認。
- OWN-WORLD：保留產品深淺色、綠色主色、系統字體、細分隔線，移除重複分類與多層卡片。
- STORY：選標的看市場 → 填寫真實成交 → 核對策略 → 確認標準或自訂計畫 → 檢查操作後庫存並保存。
- FIRST VIEWPORT：桌面 60/40，成交欄位三欄集中；小於 1100px 單欄，手機先填單再看圖，底部確認列可見。
- FORM：依使用者確認方案實作；共用十字游標與量尺為主要互動，說明使用標題旁三角形浮出框。
- FINISH：以真實元件、隔離合成帳本完成桌面／手機、深淺色、互動與保存驗證；不得使用原始帳本試單或發布正式網站。

## 實作與資料契約

- `replay-canvas` 共用複盤繪圖；新增交易使用無評分、無 MAE/MFE 的模型，價格草稿為未保存虛線；舊成交標記仍可查詢。
- 最近一／三／六個月日 K，EMA 用前一年暖機。历史補登定位成交日前後，晚於成交日的行情標為事後資訊。
- `history?mode=ohlc&live=true` 僅接受原始日 OHLC，Cloudflare 快取 15 秒、回應 private max-age=10；額外 live metadata 包含 quoteTime、tradingDate、exchangeTimezone、sessionComplete。一般历史／績效 API 不變。
- 每 30 秒更新當日 OHLC、報價與 USDTWD；隱藏暫停，前景恢復，20 秒逾時，切換資料脈絡取消請求。看盤狀態不寫草稿或帳本；提交才固定證據與估值。
- 標準依成交時間前、目前帳本全部帳戶／策略的已平倉閉環：算術平均獲利率為停利；平均虧損幅度 × 0.5 為停損。平盤與無效值排除，缺樣本不補值。
- 操作後 FIFO 均價為計算基準。新倉／反手自動帶入，加碼／減碼沿用計畫；手動修改保留，明確套用標準才恢復自動。價格最多八位有效數字，百分比一位小數。
- formatVersion=2 的 entry context 保存 standardSnapshot（截止時間、兩組樣本數與平均率、均價、方向、欄位來源）；舊 context 保留，移除欄位不再列新版待補。
- 原 FIFO、策略版本、前後股數確認、歷史重組保護、原子保存維持。無 D1 遷移，不新增券商下單能力。

## 驗證

- 計算：多空、0.5 倍停損、全部帳戶、截止時間、無樣本、極端價格、新增／加減碼／反手／平倉、手動覆寫與來源快照、原始資料不變。
- 行情：去重、有效 OHLC、缺成交量、EMA 暖機、台美時區、前一交易日完成狀態、切標的取消、隱藏暫停、草稿不受更新覆寫。
- UI：共享圖表、策略條件、說明框與 Escape 焦點、單次提交、舊證據相容；使用本機記憶體 fixture 驗證，不寫原始帳本。
