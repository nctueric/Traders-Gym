# 持倉總覽三類整併｜2026-08-28

## 目前配置

持倉總覽只保留三個主區塊，原本的帳號、更新狀態與匯入／匯出操作不變。

| 主區塊 | 顯示內容 | 可展開內容 |
| --- | --- | --- |
| 資產 | 總資產、現金、持倉、曝險、總損益、已實現與帳本摘要 | 逐月資產圖、月份明細及原始資金證據 |
| 持倉 | 部位數、停損計畫覆蓋、警示及最大持倉 | 全部持倉編輯表、成交紀錄與 K 線入口 |
| 交易計量 | 共用日期區間、獲利／虧損計分、平均報酬、勝率、總盈虧與閉環清單 | 閉環詳情與原有復盤／K 線 |

依介面精簡規範移除重複頁面跳轉；獨立「目前持倉」導覽已移除，但原本 PositionsPanel 編輯功能完整移入總覽。舊頁面狀態可回到總覽，不會變成空白。其他獨立頁（包含全歷史閉環／週統計）保留。

## 行為與資料口徑

- 逐月圖與持倉編輯預設收合，首次展開才掛載；收合後保留元件，避免重設圖表區間或成交明細展開狀態。切換帳號重設這些區塊及交易計量期間。
- 持倉停利、停損、備註仍走原本 `updatePositionPlan`／`commitPositionPlan`；使用相同持倉 ID、計畫歷史與帳號 Dataset 自動保存流程，不新增儲存欄位或資料表。
- 交易計量僅保留「總累積、年、月」，預設本月。年模式選擇年份，月模式選擇年月；移除上月捷徑與自訂起訖日期，但歷史年份與月份仍可選取。期間含起訖日，依原帳本 UTC 出場日期歸屬，不改為台北日界而重新分組。
- `cycleRangeScore` 與既有 `monthlyCycleScore` 共用原評分算式；兩個區塊使用同一份已篩選閉環。空區間顯示零筆與無樣本比例，不自動跳到最近有資料月份；無效或空白月份顯示提醒，不呈現誤導統計。
- 尚未手動選取月份時跟隨當月，使用者選定的年／月不會被報價更新改寫，切換區間類別後也保留選擇。區間只影響交易計量，不影響目前持倉或總資產。
- 逐月圖柱寬、80%空隙壓縮、整數金額、英文月份、黃入金／紅出金全部保留。

## 驗證與限制

- 181項自動測試通過；TypeScript、變更檔案 lint、建置通過，本機入口回應200。
- 整併與區間精簡新增10項回歸：本月與舊計分數值完全相同、跨月邊界、混合幣別／空單／損益兩平、無效區間、三種區間同步、歷史年份與月份選擇保留、日期刷新與閏年、閉環回溯、延遲掛載保留內容、停利停損備註與 K 線操作。
- 保留既有資產、交易行為分析、儲存序列化、反手成交與成交鏈回歸。此輪未寫入使用者帳號資料，未執行真實帳號雲端儲存／重啟的瀏覽器端驗收。
- 僅本機交付；未部署雲端，也未新增瀏覽器截圖或互動實測。

## 使用者驗收

1. 重新整理持倉總覽，確認三個主標題為資產、持倉、交易計量，側邊欄無獨立目前持倉。
2. 展開逐月圖、選取月份後收合再展開，確認選取狀態保留。
3. 展開全部持倉，編輯停利／停損／備註並離開欄位，確認帳號儲存狀態；成交明細與 K 線仍可開啟。
4. 交易計量初始為本月；確認只有總累積、年、月三個選項。選取歷史年份或月份，核對計分筆數、總盈虧與閉環清單一致。
5. 選空資料月份或清空月份，確認不顯示假勝率或錯誤範圍的交易；切換類別後回到原類別，確認先前選定的期間保留。
