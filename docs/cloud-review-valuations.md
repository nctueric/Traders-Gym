# 雲端歷史估值與復盤指標

歷史估值存於私人 R2 review-valuations/<owner>/<ledger>.json，每份帳本只保留一個可替換衍生快取，最大4MB。使用既有DB檢查登入擁有權；PUT另核對同源及session。無D1遷移，不寫成交／帳本快照，不增加歷史快照累積。

SHA-256指紋包含演算法版本、帳戶、成交、資金活動、历史日線及閉環財務輸入，不含即時報價／復盤筆記／評價。相同輸入直接讀取雲端結果，跨裝置可用；不同輸入重算。舊分頁覆寫快取可能造成下次重算，但不同指紋不會被當成有效值。按「重新整理估值」可主動重抓。行情失敗不保存該次結果，雲端失敗保留當次畫面並顯示重試。

全帳本閉環一起計算並快取；期間、策略、顯示筆數切換不重抓估值。相對平均虧損倍數仍按當前篩選重新套用分母。快取是客戶端計算的衍生結果，不作授權、下單或原始帳本依據。

新增欄位：交易損益率＝扣已登錄費用損益／累計投入。持倉時間依個股日K不重複日期計數（進出場日若有交易均計入），週末／休市日不補造；行情須涵蓋起訖區間，缺涵蓋資料顯示缺日線。MFE改為閉環引擎既有最大有利波動率，不再用mfeRetention。保留自訂排序，新欄插入損益後；MFE沿用原欄位id。

驗證：271項測試、Lint、TypeScript、建置與dry-run通過。含快取失效、損益篩選、週末、去重日線、同日成交、權限／session／同源／跨帳本／錯誤指紋測試。本機兩個獨立瀏覽器情境：首次5組歷史請求，第二個0組，R2命中；14欄、原排序保留、損益率／持倉日數／MFE一致。桌面手機檢查通過。

正式帳本發布前：179閉環皆有MFE及可涵蓋的持倉交易日日線。私人備份於忽略的outputs/valuation-cache-qa。既有Workers資源超限問題未宣告根治；本次不更動付費方案。

正式環境初次驗收：179筆閉環、14欄；首次103組歷史行情請求，第二個全新工作階段0組，雲端快取命中。已儲存到R2，原始帳本API寫入由驗收瀏覽器攔截。估值effect依序列化財務輸入觸發，避免僅物件參考或即時報價刷新造成重跑。

發布期間標準帳本v201→v203：成交、資金活動、歷史日線均一致；即時報價及3筆復盤評價由其他工作階段更新，保留現況，不覆蓋。測試帳本v15全內容雜湊一致。
