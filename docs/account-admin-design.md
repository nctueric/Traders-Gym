# 專屬管理後台設計

Operate 模式，延續 V2 的系統字體、深綠側欄、淺色工作區與綠色主要操作。桌面以帳號表格排列，手機轉為有欄位標籤的卡片。帳號、儲存狀態與操作紀錄各自成頁籤；搜尋、篩選和新增邀請保持在第一屏可找到的位置。

只有伺服器驗證的擁有者顯示「系統管理」。系統擁有者標示取代異動按鈕，不提供權限轉讓。停用／撤銷工作階段先顯示目標帳號與後果；對話框沿用既有焦點限制和 Esc 行為。操作完成顯示結果，錯誤保留在對話框內。

新帳號只需使用受邀的 Google 身分登入。登入元件未設定時，直接顯示尚未開放，不呈現會失敗的 Google 按鈕。正式 Google 驗證與 Cloudflare 上線留待 Client ID 和目標資源設定完成。

驗收截圖採隔離測試身分：桌面 1440×960、手機 390×844。設計檢查發現側欄焦點框對比不足，已改用既有萊姆綠焦點色。
