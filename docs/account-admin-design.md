# 帳戶申請與專屬管理後台設計

Operate 模式，延續 V2 的系統字體、深綠側欄、淺色工作區、白色輸入欄位與深綠主要操作。沿用 `app/globals.css` 的 `--paper`、`--card`、`--green` 與既有按鈕樣式，由 `app/account.css` 補上帳戶介面；以邊線、留白和狀態文字建立層級。輸入欄位維持 8px 圓角，申請面板延續 16px 圓角與清楚的鍵盤焦點。

申請頁依「確認 Google 身分 → 填寫 20–2,000 字申請說明 → 提交申請」排列，支援 Gmail 與 Google Workspace。待審申請可儲存修改；未通過時顯示審核原因並可重新申請。已核准者按下「進入 TraderGym」仍須重新驗證當前權限；停用、撤銷或帳號衝突時顯示聯絡管理者的提示。申請結果由使用者回到站內查詢，不另寄 Email。未提交內容與操作失敗時的輸入保留，切換身分前提醒尚未保存的內容。

後台預設開啟「申請審核」，先顯示待審數量、搜尋與狀態篩選。桌面以申請清單／完整詳情雙欄呈現，760px 以下改為上下排列；清單保留姓名、Google 信箱、說明摘要與提交時間，詳情顯示完整說明、版本及可展開的申請與審核歷程。核准與不通過操作提交目前版本以防過期審核，不通過必須填寫申請人可見的原因；送出期間停用操作，失敗保留審核備註。

另設「登入設定」、「帳號管理」、「儲存狀態」與「操作紀錄」頁籤。帳號管理保留新增邀請；桌面採帳號表格，手機轉為有欄位標籤的卡片。自助申請經核准與受邀 Google 帳號皆可取得使用權限，邀請不是唯一入口。

只有伺服器驗證的擁有者顯示「系統管理」。系統擁有者標示取代異動按鈕，不提供權限轉讓。停用／撤銷工作階段先顯示目標帳號與後果；對話框沿用既有焦點限制和 Esc 行為。操作完成顯示結果，錯誤保留在對話框內。

登入設定中的擁有者 Google 連結要求先以密碼登入、再次確認密碼，再於 5 分鐘內選擇指定 Google 帳號。連結後 Google 與密碼登入使用同一份帳本，原有帳本與密碼備援保留。Client ID 未設定時顯示待設定狀態，密碼登入仍可使用。2026-10-05 已完成 Client ID 設定、本機綁定驗收與正式 Cloudflare 發布；正式 Google 回呼已通過，仍待擁有者在正式站親自綁定後開放申請。

設計依據為 `app/apply/application-form.tsx`、`app/admin/applications-panel.tsx`、`app/admin/google-link-panel.tsx`、`app/admin/admin-workspace.tsx` 與現有樣式。側欄焦點框沿用已修正的萊姆綠焦點色。本輪獨立 reviewer 已檢查六份正常比例桌面／手機截圖，結論為可交付（ship），未要求 UI 修正；此結果不代表真實 Google 登入或正式發布已完成。
