## 使用者驗收步驟

1. 進入「交易行為分析」，選定資料區間與策略篩選。
2. 於逐筆表格選一筆交易的買入點及離場點標籤，確認分布、已評與待評即時變動。
3. 開啟同筆「看K線與回顧」，確認評分相同；改選其他標籤並補充證據。
4. 關閉詳情，確認表格同步；等待上方「背景儲存完成」再重新整理，確認評分保留。
5. 將期間或呈現筆數切換，確認三欄統計及逐筆表一致；點分布中的證據閉環回到 K 線。
6. 匯出 JSON 備份，確認 cycleReviews 中保留 entryQualityTag、exitQualityTag、qualityRatedAt。
