# Traders-Gym v1.0.0

發行日期：2026-08-29
定位：交易復盤顧問大改版前的可還原基線

## 版本內容

- 帳戶、成交、現金活動與行情資料的版本化保存。
- 持倉總覽、持倉風險與停損／目標計畫。
- FIFO 交易閉環、績效、MAE／MFE、R 倍數與出場後表現。
- 策略版本、人工交易品質標籤、行為分析與改善實驗引擎。
- 完整快照、自動儲存、本機備份、衝突保護與還原工具。
- 桌面及行動版響應式介面與無障礙基線。

## 驗證基線

- 自動測試：227 項通過，0 項失敗。
- ESLint：通過。
- Vinext 正式建置：通過。
- Node.js：22.13.0 或以上。

## 已知範圍

- M1 與 M2 已完成使用者驗收。
- M3 功能與自動測試完成，仍待使用者依真實閉環資料完成人工驗收。
- M4 週／月回顧介面尚未實作。
- 分鐘線與 MCP 行情仍屬技術尖峰，不阻擋此版本使用。
- 擬定停損與目標只屬復盤計畫，不會送出券商委託。

## 還原方式

1. 取出 Git tag `v1.0.0`。
2. 執行 `npm ci`、`npm test`、`npm run lint` 與 `npm run build`。
3. 以應用程式的完整 JSON 匯入功能載入同版本資料快照。
4. 私人交易資料只保存在本機封存區或既有私人 D1，不包含在 GitHub 原始碼或 Release 附件中。

## 後續版本

V2 改版從 `redesign/v2` 分支開始。V2 通過驗收以前，`main`、`release/v1` 與 tag `v1.0.0` 均維持可還原的 V1 狀態。
