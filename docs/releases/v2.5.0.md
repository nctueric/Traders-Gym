# TraderGym V2.5.0

## 更新內容

- 上方導覽、TG 上升 K 線標誌與集中式「帳本與備份」。
- 手機資訊分層、觸控說明面板、持倉收合與一致字級；改善深色模式及欄位高度。
- 交易量化與行為分析版面整理，盈虧結構新增總盈虧、獲利／虧損總額及平均持有天數。
- 四格摘要保留 2 × 2，依內容決定高度，桌面數字 28px、手機 24px。
- 帳本載入後背景預載歷史行情，使用隔離快取並補齊缺漏。
- 歷史快照依台北日期每日保留最後一版，保留今天及前六天；目前帳本永遠保留。新增 0009 遷移及背景清理排程。

## 驗證

432 項測試、ESLint、TypeScript、正式建置與部署 dry-run 通過。沿用正式帳本，發布前備份 D1 及最新 R2 快照，不匯入本機測試資料。

實機 iOS／Android 觸控與軟鍵盤仍需驗收；正式寄信服務維持原設定。
