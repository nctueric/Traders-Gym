# Traders-Gym v2.0.0

發行日期：2026-09-01  
定位：通過 V1／V2 對比驗收後的主要正式版本

## 版本內容

- 以「今日」取代傳統儀表板作為入口，依資料阻擋、持倉風險與待復盤順序，最多提出三項優先行動。
- 將主要導覽精簡為今日、持倉、復盤、績效與資料五個工作區，降低功能辨識與切換成本。
- 新增可略過的首次使用導覽，說明任務優先、證據追溯與改善實驗的新版工作方式。
- 新增由交易閉環直接啟動的四階段復盤流程，依序完成判斷、原因與改善實驗。
- 新增具固定基線與期限的改善實驗入口，將行為分析轉成可追蹤的下一步。
- 保留 V1 的交易計算、資料格式、D1 儲存、自動儲存、JSON／CSV 匯入與完整備份能力。

## 驗收與驗證

- 使用者已於 2026-09-01 完成 V1／V2 對比檢查，確認 V2 可轉為主要版本。
- 自動測試：232 項通過，0 項失敗。
- ESLint：通過。
- Vinext 正式建置：通過。
- Node.js：22.13.0 或以上。

## 版本與資料安全

- `main` 自本版本起代表 V2 正式主要版本。
- `v1.0.0` 與 `release/v1` 保持不變，可隨時還原或進行 V1 必要維護。
- `v2.0.0` 為不可變的 V2 正式還原點。
- GitHub 原始碼與 Release 不包含私人交易資料、環境檔、本機 D1 或備份檔。

## 還原方式

1. 取出 Git tag `v2.0.0`。
2. 執行 `npm ci`、`npm test`、`npm run lint` 與 `npm run build`。
3. 以完整 JSON 匯入功能載入本機保存的交易快照。
4. 若需回到改版前介面，改取 `v1.0.0`；V1 資料契約與備份格式仍受保留。
