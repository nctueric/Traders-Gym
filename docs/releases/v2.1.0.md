# v2.1.0 — 帳號與歷史快照整合

日期：2026-09-14。基準：正式 v2.0.0。此版本封存目前可本機驗收的整合程式；不是 Sites 已完成上線或完整驗收的宣告。

## 變更

- 保留 V2.0 五個工作區、交易計算與復盤功能。
- 加入 Google 登入程式、session、邀請、停用、強制登出及帳本隔離。
- 加入 D1／私人 R2 大型完整快照、版本衝突檢查及雜湊校驗。
- 提供歷史快照列表、下載、還原成新版本及清理預覽；最近七天完整保留、三十天內每日保留，保護有效帳本與初始版本。
- 區分雲端已儲存、本機備援、等待重試與儲存失敗；更新資料使用說明。
- 保留獨立的本機驗收工具，測試登入入口不包含在正式建置。

## 驗證與限制

本機自動測試、ESLint、TypeScript 與正式建置通過。Google 真實登入與 Sites 雲端完整驗收依使用者要求暫停；目前 Sites 仍為既有第 24 版。使用者已確認 ChatGPT 身分對應方案：私人 Sites 首次擁有者請求綁定平台身分至獨立試用帳本，後續逐次檢查相同身分；不佔用 Google system_owner，不認領 primary，管理範圍限自己的歷史版本。

深淺色切換、真實第二身分、跨裝置、線上故障復原及七日試用仍待完成。不得將本機測試身分當成正式登入。詳細結果與備份／復原程序見 [試用紀錄](../sites-trial-status.md)。

## 升級注意

雲端部署需套用 0001–0004 遷移，提供 DB 與 SNAPSHOTS 綁定；本次 Sites 使用 SITES_TRIAL_AUTH=true，Google 模式日後另設正式 Google Client ID；正式環境不能啟用 LOCAL_ACCOUNT_SERVICE。發布前先備份並確認帳本來源。資料庫遷移後，不應回退到缺少帳號隔離的舊 API。

此次 GitHub 推送保留在整合分支並建立 v2.1.0 標籤；main 仍遵循 PR 與 CI 合併流程。
