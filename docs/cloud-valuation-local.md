# 統一雲端帳本與全域計價：本機實作與驗收

驗收日期：2026-10-07。範圍為 v2.5.0 工作目錄；正式發布及正式資料庫 migration 尚未執行。

## 完成的行為

- 正式帳本僅經由 D1 擁有權／版本索引與 R2 完整快照儲存。保留原帳本 ID、版本衝突與安全合併規則，沒有批次重寫既有帳本。既有有效的 D1 內嵌快照可讀取；後續正常儲存寫入 R2。
- 移除本機檔案儲存適配層、瀏覽器帳本寫入、pending／recovery 備份寫入及私人績效的持久快取。訪客帳本及偏好維持獨立記憶體。
- 明確操作立即進入序列化儲存佇列；草稿與連續文字編輯停止 1 秒後儲存。只有伺服器確認成功才顯示已儲存。失敗保留當頁記憶體、提供重試與原有匯出；不退回本機模式。
- 已知離線時停用帳本修改及匯入提交。切換帳本／登出先完成儲存；無法儲存時可先匯出，再明確放棄修改。未存資料會觸發重整／關閉提示。
- JSON／CSV 選檔、解析、驗證、幣別確認、摘要、取消、確認取代沿用原規則。匯入成功訊息等到雲端確認才顯示。JSON 匯出保留完整格式；未存修改會先提示。
- 「舊本機資料轉移」唯讀列出可驗證擁有者的瀏覽器資料與舊伺服器檔案，支援匯出。轉入透過既有匯入確認，不自動覆蓋或刪除舊資料。

## 計價與偏好

共用 USD／TWD 偏好適用會員、訪客、簡易／完整登錄與其他工作台頁面。資產頁將選單放在「資產」標題旁，與「新增資金」同列；手機保持同列並以可及名稱識別選單。

登入限定 `GET /api/preferences`、`PATCH /api/preferences` 只處理目前會員，不能指定其他使用者。欄位白名單為 `valuationCurrency`、`entryMode`、`onboardingDone`、`holdingsColorScheme`、`reviewColumns`。未設定欄位可一次讀取可辨識會員的舊偏好；後續只雲端同步。訪客不呼叫會員偏好 API。

目前資產使用有效當前匯率；歷史現金、持倉與外部資金流使用各日有效匯率。日終績效、回撤與 TWD 的 QQQ／SPY 調整後收盤價逐日換算。已實現損益使用平倉市場日匯率；原幣成交價、費用、停損／停利、交易報酬率、勝率與 R 倍數保留原定義。沒有足夠匯率或行情時顯示缺口，不補造數字或將部分金額當完整總額。

## 本機環境與 migration

開發伺服器使用 Miniflare 的 D1／R2 模擬綁定，執行與正式相同的帳本與偏好 API。`LOCAL_CLOUD_DIRECTORY` 指定隔離模擬資料目錄；`LOCAL_RECORD_DIRECTORY` 僅用於舊資料唯讀檢查。缺 D1／R2 綁定明確失敗，沒有檔案儲存備援。

本次唯一新增 migration 是 `drizzle/0010_cloud_preferences.sql`，新增偏好 JSON 欄位。已在隔離本機模擬資料庫驗證，尚未在正式資料庫執行。正式部署前須先安排這項 migration。
