# 全站 UI 實作與驗收｜2026-08-28

## 結果與界線

依 Impeccable 的產品介面規範完成本機全站整理：保留深綠側欄、淺色內容、少量萊姆綠識別，統一系統字體、數字、表格、提示、控制項與可及性視窗。

本次沒有部署，沒有變更 API、資料庫、匯出格式或 lib 內的計算／儲存引擎，也沒有對真實帳號寫入測試評分。以本機未提交版本為基準，保留既有全寬內容與寬螢幕使用能力；既有 responsive-layout 測試改為檢查版面能力，不鎖定舊 padding 字串。

## 已完成的介面

- 八個主頁與入口順序保留；桌機 230px 側欄，手機可展開導覽。
- 緊湊頁名、帳號與狀態列；載入期間停用資料操作，失敗提示獨立呈現。
- 總覽分為三項財務摘要與次要帳本統計；持倉風險先於月計分表。
- 持倉表分組欄位、固定標的欄、區域捲動與一致的計畫輸入。
- 績效比較基準在圖表標題旁；成交與資金活動同頁切換；全部閉環先於每週統計。
- 策略編輯保留三組規則、草稿、啟用版本與歷史版本；修正窄螢幕欄位撐寬。
- 行為分析順序為：摘要／篩選 → 人工標籤分布 → 快速評分 → 盈虧結構／全時段曲線 → 策略稽核 → 矩陣／客觀旁證。四個區段跳轉與快速評分捷徑可直接使用。
- 詳情使用原生 modal dialog；固定標題、動態標題高度、區段跳轉、Esc、首尾焦點循環及關閉後焦點返回。新增與匯入保留可捲動內容及操作列。
- 全部人工單選選項保留，支援方向鍵循環及空白鍵選取；散點圖另提供可由鍵盤開啟證據的資料表。
- 全時段曲線增加可操作的月份檢視選單，但仍只採策略／版本篩選，不套用期間或最新筆數限制。
- 測試中心分開呈現核心計算與帳號資料問題，以文字標示通過／警告／失敗。

建置仍會輸出 vinext 既有的路由靜態分類提示；沒有建置失敗。

新增的 UI 計算一致性測試不是只比 CSS 或畫面文字：以修改前的 TrainingWorkspace 原始碼產生基準，紀錄五個分析引擎的完整輸入及輸出，再與新 UI 比較。七組情境摘要雜湊完全一致：

1. 多空、USD／TWD、損益兩平及未評分混合。
2. 缺少行情與匯率。
3. 舊資料缺少評分／策略容器。
4. 空帳本。
5. 最新 10 筆。
6. 單月篩選。
7. 策略＋版本＋月份＋筆數組合。

例如最新 10 筆時，評分、結構與稽核使用 10 筆，全時段曲線仍用 32 筆；指定策略版本及月份時，區間分析用 3 筆，全時段曲線用該策略的 21 筆。

### 尚需人工複驗

- 目前瀏覽器控制介面無原生縮放設定：上表是等效視窗重排，不代表已操作瀏覽器 200% 原生縮放。正式驗收時請在實際瀏覽器複驗一次。
- 匯入測試透過 QA 專用按鈕建立合成 File 並觸發原檔案控制項；實際系統檔案選擇器無自動化能力，需人工複驗。JSON 解析、取代確認與背景儲存已實測；CSV 匯入規則由既有自動測試涵蓋。
- 未使用真實帳號執行寫入、刪除、匯入或策略發布；真實資料操作仍由使用者確認後進行。

## 重現方式

一般驗證：

```sh
npm test
npx tsc --noEmit --incremental false
npm run lint
npm run build
```

隔離互動驗收：

```sh
node tests/serve-ui-fixture.mjs
```

此命令以隨機本機埠啟動，只在記憶體保存資料；終止程序即捨棄測試快照。終端會印出網址，可加以下 scenario 查詢參數：

- rich：混合幣別、多空、兩平、未評分與有策略的完整資料。
- empty／missing／legacy／long-text。
- save-error／load-error／stale／slow。

不要將驗收入口或假資料連接正式 API。QA 元件僅由獨立測試打包程式載入，不會進入正式頁面。測試改動後請等待既有 900ms 自動儲存完成，再切換網址；這個儲存時機未變更。
