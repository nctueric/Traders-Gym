## 核對結果

- 原有資產、現金、持倉、曝險、交易損益、期間報酬、QQQ、熱力圖、風險摘要、持倉計畫及交易計量組件保留。
- 原有「逐月資產變化圖」「全部持倉計畫」預設折疊及詳情入口保留。
- 財務計算模組、API、資料庫結構與同步計時未修改。
- 414 項既有回歸測試通過；另有 3 項嵌入帳本管理測試，涵蓋切換前保存、重複點擊、未同步阻擋、改名失敗保留、版本重試、回收確認及還原。
- Lint、TypeScript、建置通過。建置保留 vinext 既有的動態路由分類提示。
- 實際瀏覽器檢查1440px、390px及使用者約1092px寬度；手機 document scrollWidth 等於390px。帳號選單 Escape 返回觸發按鈕。
- 深色視覺透過實際 DOM 與正式 CSS 的靜態副本驗證，不模擬行情或寫入帳本；非完整的系統主題切換端到端測試。
- 原始帳本未做新增／刪除／匯入驗收；破壞性操作由隔離測試覆蓋。
- 本機即時行情自然變動，截圖金額不作數值相等證據；固定測試資料的既有計算與保存回歸測試作為依據。
