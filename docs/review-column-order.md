# 復盤欄位順序

逐筆交易復盤的 12 個表頭支援滑鼠／觸控拖拉，放開時一起移動表頭和資料欄。拖曳靠近表格邊緣時可橫向捲動；移出表格或按 Escape 可取消。欄位不再固定在左右邊緣，以免與自訂順序衝突。

表頭按鈕可使用左右方向鍵移動，Home／End 移到首尾，有焦點標示及讀屏狀態通知。提供還原欄位順序。

偏好保存在此瀏覽器 localStorage（traders-gym.review-columns.v1），不寫入帳本、不跨裝置同步。非法或舊版設定會去除未知／重複欄位並補齊新欄位；儲存不可用時仍可當次調整並告知。

驗證：268 項測試、Lint、TypeScript、建置及 dry-run 通過。以本機虛構帳本實測桌面拖拉、欄與資料對齊、重整保存、鍵盤移動、K 線開啟、還原順序及手機觸控，均通過。
