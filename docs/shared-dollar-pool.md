# 共用美元資金池：投入時部位比

使用者確認美股及台股共用美元本金，取代先前逐帳戶要求獨立期初資金的假設。

- 所有帳戶的入出金、成交現金流及已登錄費用合併至美元資金池；台幣現金流使用發生日或之前最近歷史 USDTWD。
- 持倉以最後投入日或之前最近收盤價估值，再以估值日匯率轉成美元。空單按負持倉計算。
- 分子是各次建倉／加碼按當日匯率換算的美元投入總額；分母是最後投入日日終美元淨資產。
- 期初餘額視為生效時點的共用現金餘額，不重複加入較早現金流；既有持倉仍計入。
- 缺行情或歷史匯率仍顯示資料缺口，不使用今日或未來行情。
- 本次範圍是復盤表的部位比；原幣損益／投入欄及原幣相對平均虧損倍數保持既有定義。
- 不新增 API、資料庫遷移或虛構台幣本金，不修改成交、資金活動或復盤紀錄。
