# 交易復盤顧問 v2.1.0

以 V2.0 正式版為基準的登入、帳號隔離與歷史快照整合版本。雲端小型快照存於 D1，大型快照存於私人 R2；本機模式存於指定資料夾，瀏覽器暫存與 JSON 匯出提供備援。

本版程式已完成本機自動驗證；Google 真實登入及 Sites 雲端完整驗收暫停，尚未發布到 Sites。版本標籤不代表線上驗收完成。詳見 [v2.1.0 版本說明](docs/releases/v2.1.0.md) 與 [試用紀錄](docs/sites-trial-status.md)。

## 功能

- 以「今日」為入口，依資料阻擋、持倉風險與待復盤順序整理優先行動
- 精簡為今日、持倉、復盤、績效與資料五個主要工作區
- 以可追溯交易證據引導四階段復盤，並建立有期限的改善實驗
- 新版首次使用導覽與任務導向摘要，先呈現需要決定的事項再展開數據
- 建立、刪除與備份成交紀錄
- 以登入身分隔離帳本；保留帳本內的券商帳戶
- 擁有者管理邀請、停用與工作階段
- 雲端歷史快照下載、還原及保留策略清理
- 依帳戶與股票代號進行 FIFO 閉環配對
- 計算實現損益、報酬率、持倉日數、MAE 與 MFE
- 顯示尚未平倉部位與資料品質
- 持倉即時報價：載入時立即更新，其後每30秒更新最新價、漲跌幅與未實現損益
- 內建瀏覽器測試中心及 Node 自動測試
- 行情來源抽象化：歷史計算使用 JSON 日線；即時價經伺服器行情適配層取得，預留 TradingView MCP 介接
