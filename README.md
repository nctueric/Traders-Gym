# TraderGym v2.5.0

投資組合績效回顧、持倉風險與集中式交易登錄。歷史績效支援 QQQ／SPY 同期比較，交易登錄與複盤共用 K 線互動。

正式服務部署於 [Cloudflare Workers](https://tradergym.app)，支援 Google 主要登入、Mail 備援及 D1／私人 R2 保存。詳見 [v2.5.1 版本說明](docs/releases/v2.5.1.md)。正式帳本統一雲端儲存；本機開發使用隔離 D1／R2 模擬綁定，登入設定不隨程式發布。

## 功能

- 登入後直接進入持倉，集中查看資產、風險及交易計量
- 持倉、復盤、績效與資料四個主要工作區
- 以可追溯交易證據引導四階段復盤，並建立有期限的改善實驗
- 交易計量依序呈現核心摘要、盈虧比較與完整閉環明細
- 建立、刪除與備份成交紀錄
- 以登入身分隔離雲端帳本；保留帳本內的券商帳戶
- USD／TWD 全域計價，逐日歷史匯率估值；會員偏好雲端同步
- 明確操作立即儲存、草稿停止輸入 1 秒後儲存；失敗只留當頁並提供重試／匯出
- 擁有者管理邀請、停用與工作階段
- 雲端歷史快照下載、還原及保留策略清理
- 依帳戶與股票代號進行 FIFO 閉環配對
- 計算實現損益、報酬率、持倉日數、MAE 與 MFE
- 顯示尚未平倉部位與資料品質
- 持倉即時報價：載入時立即更新，其後每30秒更新最新價、漲跌幅與未實現損益
- 內建瀏覽器測試中心及 Node 自動測試
- 行情來源抽象化：歷史計算使用 JSON 日線；即時價經伺服器行情適配層取得，預留 TradingView MCP 介接

## 本機驗證

```bash
npm test
npm run lint
npm run build
```

訪客 `/demo` 先取得真實市場行情與匯率，再以最近一年交易日產生示範買賣。USD 50,000 僅為示範本金，持倉與績效依實際行情計算；不生成股息或策略，未模擬交易成本。訪客資料只留在記憶體，離開／重整／重置後重建。

市場資料由會員與公開唯讀 API 共用適配層，可能延遲；保留來源、實際報價時間及缺口。公開端點需要 `MARKET_RATE_LIMITER` 綁定（120 次／60 秒／IP），本機與正式設定產生器均包含此設定。

原始 Yahoo 回應測試夾具與來源雜湊位於 `tests/fixtures/market/`，只含公開市場資料。舊 `public/sample-trading-data.json` 為獨立匯入樣本，不是訪客行情來源。

雲端帳本與計價改版的本機驗收及發布前 migration 說明：[驗收紀錄](docs/cloud-valuation-local.md)。
