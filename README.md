# 交易復盤顧問 v2.3.0

投資組合績效回顧、持倉風險與集中式交易登錄。歷史績效支援 QQQ／SPY 同期比較，交易登錄與複盤共用 K 線互動。

正式服務部署於 [Cloudflare Workers](https://traders-gym.nctueric.workers.dev)，沿用個人密碼登入及 D1／私人 R2 保存。詳見 [v2.3.0 版本說明](docs/releases/v2.3.0.md)。本機私人帳本及登入設定不隨程式發布。

## 功能

- 登入後直接進入持倉，集中查看資產、風險及交易計量
- 持倉、復盤、績效與資料四個主要工作區
- 以可追溯交易證據引導四階段復盤，並建立有期限的改善實驗
- 交易計量依序呈現核心摘要、盈虧比較與完整閉環明細
- 建立、刪除與備份成交紀錄
- 以登入身分隔離帳本；保留帳本內的券商帳戶
- 擁有者管理邀請、停用與工作階段
- 雲端歷史快照下載、還原及保留策略清理
- 依帳戶與股票代號進行 FIFO 閉環配對
- 計算實現損益、報酬率、持倉日數、MAE 與 MFE
- 顯示尚未平倉部位與資料品質
- 持倉即時報價：載入時立即更新，其後每30秒更新最新價、漲跌幅與未實現損益
- 內建瀏覽器測試中心及 Node 自動測試
- 行情來源抽象化：歷史計算使用 JSON 日線；即時價經伺服器行情適配層取得，預留 TradingView MCP 介接
